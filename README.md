# Catálogo Plaza Vea - Módulo Modular

Módulo de gestión de catálogo de productos para la tienda piloto de Supermercados Peruanos S.A. (Plaza Vea). Automatiza el registro, actualización, búsqueda y listado de productos, reemplazando el proceso manual que retrasaba la apertura diaria de caja.

## 📋 Descripción

Este proyecto resuelve el problema del equipo de operaciones de la tienda piloto, que administra un catálogo de 1,200 referencias y actualizaba los registros de forma manual. La solución implementa persistencia en archivo de texto para conservar los datos entre sesiones.
